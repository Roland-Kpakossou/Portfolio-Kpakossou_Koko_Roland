Projets

Sports-par-Bus – Système de Gestion de Voyages Sportifs

Développement full-stack d'une plateforme web complète permettant aux équipes sportives de gérer leurs déplacements. Conception d'une base de données MySQL normalisée avec des procédures stockées PL-SQL pour optimiser les requêtes complexes. L'application PHP sécurisée implémente un système d'authentification à trois niveaux (administrateur, entraîneur, joueur) avec gestion des réservations en temps réel, génération automatique de factures et tableaux de bord statistiques. Le projet inclut des mesures de sécurité contre les injections SQL et les attaques XSS.

WiFi-Map Analyzer (Java)

Application de cartographie et analyse de réseaux WiFi développée en Java. Le programme scanne les points d'accès disponibles, mesure la force du signal RSSI en décibels, et génère des cartes thermiques interactives pour visualiser la couverture réseau. J'ai implémenté des algorithmes d'optimisation utilisant des structures de données avancées (arbres binaires, tables de hachage) pour recommander les meilleurs emplacements d'antennes. L'interface graphique Swing permet l'export des données en formats CSV et JSON pour analyse ultérieure.

Automatisation de Données (Python/C++)

Système d'extraction et transformation de données combinant Python et C++ pour le traitement haute performance. J'ai développé des robots Python qui collectent des données sur le web. Les données sont ensuite nettoyées et analysées par un moteur C++ optimisé , avec génération de rapports PDF automatiques contenant des visualisations de tendances.

Jeu de Scrabble

Jeu de Scrabble en Python développé pour un projet d'algorithmique. J'ai implémenté la logique fondamentale du jeu avec un système de plateau interactif, gestion des lettres disponibles, et validation des mots à l'aide d'un dictionnaire intégré. Le programme permet de calculer les scores en respectant les cases spéciales (lettre/ mot compte double/triple) et inclut une interface en ligne de commande intuitive pour deux joueurs.

Gestion des Élections (C++)

Programme de simulation électorale utilisant les concepts avancés de la POO. J'ai modélisé une circonscription avec héritage (candidats, partis politiques, bureaux de vote) et polymorphisme pour différents types de scrutins (majoritaire, proportionnel). L'interface Qt offre des visualisations graphiques des résultats (diagrammes circulaires, cartes choroplèthes). Le projet inclut une suite complète de tests unitaires avec Google Test couvrant 95% du code.

Creation d'une plateforme de banque virtuelle (Python)

Application de gestion bancaire simplifiée avec interface en ligne de commande et base de données. J'ai implémenté les opérations bancaires fondamentales : création de compte, virements sécurisés avec vérification des soldes, historiques de transactions consultables, et calcul des intérêts mensuels. Le système inclut un module de sécurité avec hachage des mots de passe. L'interface utilise des menus intuitifs avec validation en temps réel des saisies.
